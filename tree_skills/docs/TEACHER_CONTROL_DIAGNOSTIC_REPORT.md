# 冻结教师四组控制诊断（2026-11-01）

已完成 40 个新场景 × 4 种策略，共 160 局正式实验，另有 4 局独立冒烟测试。当前 checkpoint 在本项目的 10v10 原生兵种环境和 H=4 输入协议下，没有显示出优于原规则的优势。不能再把当前结果仅解释为“教师被治疗接口限制住了”；也不能据此断言 MARL-GPT 在原训练环境中能力差。

建议暂缓直接蒸馏、扩大树容量和从头训练教师。优先核对训练/部署配置、做医疗动作有效性过滤的单项对照；若仍无收益，再从现有权重定向微调或筛选更适配的教师。`qualified=false` 保持不变。

这些是小样本机制筛选结果，不能据点估计宣称教师稳定更差。例如，原始分布的 C−A 胜率差为 −10 个百分点，配对 bootstrap 描述区间为 [−35,+15] 个百分点，exact McNemar p=0.6875；D−A 为 −5 个百分点，区间 [−25,+15]，p=1.0。诊断分布 D−A 为 −15 个百分点，区间 [−40,+10]，p=0.453125。这里有多个探索性比较，没有据此作正式显著性或等效性声明。

A/B 零胜负分歧产生的退化 bootstrap [0,0] 不能解释为两策略总体等效；机器报告保留了退化警告和保守不确定性界。上一轮已见 40 局中的“多赢 1 局”，没有在本轮新场景中重复出现。

## 行为证据：不只是候选接口窄

### B：实际干预发生，但仍没有胜率收益

- 共 2316 个评分组，2111 个单候选、205 个多候选（8.85%）；多候选来自 22 局。
- 原始分布为 1142 组/105 个多候选；诊断分布为 1174 组/100 个多候选。增加含医疗艇场景，并未自动解除规则候选筛选造成的低覆盖。
- 87 次改配建议中，75 次进入最终治疗动作；其中 56 次 SC2 接受、19 次 `AlreadyTargeted`。
- 另外 12 次最终执行 keep，保留目标均不同于教师建议目标。因此本批场景确实存在后续规则覆盖，不能沿用上一轮“没有 keep 覆盖”的结论。
- 75 次提交没有其他拒绝、未知反馈、反馈映射错误或观察错误。接受、重复目标、持续旧订单和实际治疗收益仍是不同概念。

### C/D：完整动作下仍有大量满血治疗请求

| 医疗艇指标，40 局 | A | B | C | D |
|---|---:|---:|---:|---:|
| 原生治疗请求数（不含 keep） | 2228 | 2197 | 2154 | 2571 |
| 观察时目标满血的治疗请求 | 4 | 5 | 1186 | 1610 |
| 上项占治疗请求比例 | 0.18% | 0.23% | 55.06% | 62.62% |
| 引擎 `TooMuchLife` 拒绝 | 0 | 0 | 1167 | 1596 |
| 医疗艇观察错误 | 0 | 0 | 0 | 0 |

原生 SMAC mask 会允许部分满血治疗目标，C/D 忠实保留该接口。因此这不是把被 mask 禁止的动作错误提交给环境，而是教师在宽松原生候选中偏好大量当前无法产生有效治疗的新请求。满血计数依据记录的可见状态快照，受快照精度影响；引擎反馈另外统计。观察时目标满血数与引擎拒绝数不必相等：观察、提交及后续状态变化不是同一时刻。

在多个医疗艇同时提出治疗/保持治疗的步骤中，C 有 653/718 步共享目标，D 为 653/802。多人集中治疗本身可以合理；这些计数只能说明其行为明显不同于原规则的一对一分配，不能直接当作错误率。

`TooMuchLife`、`AlreadyTargeted` 和 Success 均不能直接换算成治疗损失或收益；需要后续单项干预才能确认满血过滤是否改善胜率。本轮不据这些动作计数做独立样本显著性检验。

### 两个首次动作分歧案例

事后选择一个负向翻转和一个正向翻转用于解释，不作为独立性能证据。两例首次分歧均发生在 loop=2，完整观察相同，且只改变医疗艇动作。

- 第 3 局（seed=10002）：A 胜、C 负。A 的两台医疗艇向东移动，C 的两台都请求治疗满血的 u1 Marine（45/45 HP），均收到 `TooMuchLife`。
- 第 4 局（seed=10003）：A 负、C 胜。A 的三台医疗艇向南移动，C 改为向西移动，三条指令均被接受。

案例表明完整教师既可能改善，也可能恶化具体轨迹。不能把整局胜负归因于首次动作；完整记录在 `artifacts/teacher_diagnostic_20261101/first_divergence_cases.json`。

## 关于教师与重训的判断

1. **当前尚不是已证明优于基线的蒸馏教师。** B 没有重复上轮的微小提升，C 放开医疗艇动作没有出现明确收益，D 完整团队控制也没有显示优势。继续拟合它的 logits 可以提高模仿一致率，但不能据此承诺胜率提升。
2. **不能只归因于接口，也不能归因于树。** 本轮直接运行教师，没有学生树；把树扩成 192 棵无法解决已经出现在教师本身执行中的问题。C/D 排除了“只要放开动作就会明显变强”的简单解释，但没有分别识别候选过滤、keep、联合分配和移动选择的贡献。
3. **还不能确定是模型本身弱，还是部署域不匹配。** 这是原生兵种版本、H=4 的本项目测试，不是完整官方基准复现。checkpoint 记录的实际数据配置路径为 `config/dataset_all_jobs_3.json`，本地归档中没有该文件，不能用另一份示例数据清单冒充真实训练覆盖。配置里的 `history_len=10` 是位置嵌入容量，不能据此把推理历史强行设为 10。
4. **不建议从零重训。** 先在与训练更接近的官方环境/输入配置下复核 checkpoint，并做一个保持其他条件不变的医疗动作过滤对照：只排除当前无法治疗的满血目标，仍允许移动/停止。再单独考察 keep 覆盖，避免同时修改多个约束而无法解释结果。
5. **若仍不优于原规则，优先适配现有权重。** 当前部署目标是规则地面部队＋医疗 skill，则固定这些地面规则，以团队回报微调医疗艇策略，或筛选更适配的 checkpoint。需要环境奖励或更好的专家反馈；重复用同一教师自己的标签训练，不是改善教师能力的充分方法。
6. **等教师通过独立验证后再蒸馏。** 排序训练应重点覆盖多候选和协同取舍，按局划分数据，避免单候选零标签主导损失。如果最终需要 zero-shot transfer，最终目标场景不能参与教师微调或树训练；仅更换同一生成分布的种子不等于跨域迁移验证。

若以后出现“D 强、C 弱”，也不能仅据这两个组认定协作失配：还可能只是教师地面策略更强。需要补“教师地面＋规则医疗艇”的交叉组才能进一步区分。本轮 D 并未表现出这种优势。
