# DATA_PROTOCOL：轨迹采集、教师标注与样本组

权威实现：`tree_skills/data/labeling.py`、`tree_skills/medivac/features.py`。

## 采集范围

- 第一批：A 真实轨迹 + B 真实轨迹（B = 教师医疗机评分 + 原 skill 执行，贴近目标系统）。
- 可选全教师 T 轨迹单列来源；若缺真实技能角色/订单历史，对应学生特征字段按缺失标记，不伪造。
- 逐样本组保存：原始局部观察与历史（官方编码）、结构化可见状态、合法候选、实际确认订单、原计划、最终执行动作、覆盖原因、角色/预算、环境奖励与终止、教师完整基础动作 logits、候选过滤原因、版本哈希。教师 logits / critic / 回报 / 文本评分分栏，不混用。
- 胜负不筛样本：输局有效数据保留；赢局不逐步标对。
- 关键状态（多候选、多人受伤、教师与基线分歧）与普通随机样本都保留并记录采样概率。
- 泄漏禁令：特征与教师输入不含未来观测、最终胜负、隐藏敌情、场景编号；初始全场信息只用于审计哈希。训练/验证/测试按对局划分，样本组 `(episode_id, game_loop, healer_id)` 的候选永不跨集。

## 标签定义（条件排序）

对 healer H 的原规则合法治疗候选组 {V}（环境门控 + 订单预留过滤后），教师原始 actor logits z_T：

```
y(H,U) = z_T(H, heal_slot(U)) - mean_{V} z_T(H, heal_slot(V))
```

- heal_slot 是"友军→治疗槽"的显式双向映射，不复用攻击敌人映射。
- 仅有限合法 logits；屏蔽值、补齐槽、keep 扩展动作不进均值与损失。
- 教师整体动作分布另存（"教师本步是否倾向治疗"是独立诊断，治疗内部最高分 ≠ 应该治疗）。
- 固定 H 且每机恰好匹配一次时，逐行减常数不改联合匹配最优解——该假设仅在本设定成立；未来允许不治疗须重设回退基准。
- 教师分差/熵/一致性仅诊断；不删低置信样本、不把高置信等同正确。
- 轨迹结局、教师标签、原策略行为三个字段分开存，绝不合并。

## 历史与单位映射契约

- 历史按真实环境步推进，逐局逐单位独立；同快照重复评分不追加历史；死亡/重置不串旧记录。
- 上下文长度、位置索引、初始填充、截断依检查点定义；超容量显式报错。
- 死亡单位 0 动作与存活 Stop 保持原语义；补齐槽与非法动作严格屏蔽。

## 权重

每个样本组总权重 1/N_groups（`labeling.group_weight`），候选多的组不自动放大。

## DAgger 式补标（第二阶段，默认两轮封顶）

C/D 只在新训练场景运行 → 冻结主教师对访问状态重标 → 聚合重训（旧状态覆盖保持）→ 每轮 ≤100 局；不用验证/测试集收标签；学生赢局不当专家答案；是监督聚合不是 PPO。
