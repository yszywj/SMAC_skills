## 为什么没有训练样本

本次候选要求：原树本次仍选择 STOP，已连续达到第三个 STOP 窗口，有足够能量、自身血量满足条件，且存在距离范围内可用的伤员和合格移动方向。

对完整 BASE 轨迹检查：共有 **3,235 条医疗机决策，377 条 STOP，0 次候选机会**。STOP 的首要拒绝原因如下；同一记录可能还有其他条件不满足，此表按首要原因计数，合计 377。

| 首要拒绝原因 | STOP 记录数 |
|---|---:|
| 尚未连续达到第三个窗口 | 142 |
| 当前仍有治疗订单 | 119 |
| 没有未被其他医疗机预留的伤员 | 74 |
| 能量不足 | 40 |
| 伤员距离超过 12 | 2 |

达到至少三窗的 76 条 STOP 中，41 条的伤员已经被其他医疗机预留，33 条没有符合条件的受伤地面单位，2 条的最近可用伤员距离分别约为 13.936 和 12.108。独立重算停止窗口和患者可用性，与记录一致；未发现计数失效或缺失候选审计信息。

这说明当前选择的纠错问题在该开发分布中覆盖不足。不能把无候选机会的对局编造成零收益样本，也不能用相同场景的重复运行冒充新的独立场景。
